# C.H. Robinson

> C.H. Robinson is one of the world's largest third-party logistics (3PL) providers. Its Navisphere
> platform exposes a single OAuth 2.0-secured REST contract covering rating, orders and booking,
> events, visibility, shipments, financials, documents and parcel labels, for both shippers and
> carriers. This file was GENERATED by API Evangelist from C.H. Robinson's own published contract
> and pages - C.H. Robinson does not serve an llms.txt of its own (developer.chrobinson.com/llms.txt
> returns the developer-portal SPA shell, HTTP 200 text/html, not a text file).

## APIs

- [C.H. Robinson REST APIs (OpenAPI 3.0.0)](https://api.navisphere.com/api/B2B/Portal/v1/documentation/swagger.yaml): The single first-party contract - 32 paths, 35 operations, 321 schemas, info.version 2.0.0.
- [API reference](https://developer.chrobinson.com/api-reference): Redoc rendering of the contract above.
- Production base URL: https://api.navisphere.com
- Sandbox base URL: https://sandbox-api.navisphere.com

## Authentication

- [Authentication guide](https://developer.chrobinson.com/api-reference#tag/Authentication): OAuth 2.0 client_credentials against POST /v1/oauth/token with client_id, client_secret and audience https://inavisphere.chrobinson.com. JWT bearer token, valid 24 hours. Credentials are issued during onboarding; there is no self-service signup.

## Products

- Rating - POST /v1/quotes, POST /v1/quotes/freight-class-estimate (contractual, carrier-select and transactional truckload quotes; NMFTA density-based freight classification)
- Orders and Booking - POST/PUT/DELETE /v1/orders, POST /v1/orders/quotes, POST/PUT/DELETE /v1/gfbookings
- Events - GET /v2/events plus a partner-hosted callback for near real-time order and shipment events
- Visibility - POST/GET/DELETE /v2/visibility/shipments, /v2/visibility/orders, /v2/visibility/invoices, GET /v2/visibility/milestones
- Shipments (carrier side) - POST /v2/shipments/available/searches, POST /v1/shipments/{loadNumber}/offers, POST /v1/shipments/books, POST /v1/shipments/milestones
- Financials - GET /v1/financials/payments, /v1/financials/invoiceSummaries, /v1/financials/invoiceSummaries/{invoiceNumber}
- Documents - generated and signed BOLs, invoice PDFs, load document retrieval, carrier document upload
- Labels - POST /v1/labels (small parcel labels; requires a parcel carrier account configured in Navisphere)

## Not published

- No MCP server, no A2A agent card, no GraphQL, no gRPC, no WSDL.
- No /.well-known documents on any host (security.txt, api-catalog, openid-configuration, apis.json all 404 or soft-404).
- No AsyncAPI; the event surface is four HTTP callbacks documented inside the OpenAPI contract.
- No idempotency key, no pagination contract, no dated changelog, no deprecation policy, no SLA, no trust center.
- No first-party SDK for these APIs. The Chr.Avro NuGet family is genuine C.H. Robinson open source but is Avro/Kafka tooling, not an API client.
